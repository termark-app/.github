# Contributing to Termark Public Resources

Thank you for helping improve Termark's public resources.

Termark is commercial software. The public repositories contain official product information, documentation, examples, and community resources; they do not contain the commercial client source code.

## Useful contributions

Contributions may include:

- documentation corrections and clearer usage guidance;
- reproducible product reports and fact corrections;
- terminal highlight rules and safe examples;
- accessibility, localization, and broken-link fixes.

Use [Termark Discussions](https://github.com/termark-app/termark/discussions) for product questions, feature requests, and bug reports. Documentation changes may be proposed against [`termark-document`](https://github.com/termark-app/termark-document).

## Safety and privacy

Never include credentials, private keys, API tokens, real production server details, customer data, or private logs. Replace sensitive values with clearly marked synthetic examples.

Security vulnerabilities must be reported privately under the [security policy](https://github.com/termark-app/termark/security/policy), not through a public pull request or discussion.

## Pull requests

Keep changes focused, explain the problem and verification performed, and avoid unsupported product claims. By submitting a contribution, you confirm that you have the right to provide it and that it does not contain confidential or third-party restricted material.
